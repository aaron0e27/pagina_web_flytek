# ORION — rediseño de página de producto

Esta carpeta es una copia independiente del proyecto recibido. El archivo ZIP original no fue modificado.

## Ejecutar

```bash
npm install
npm run dev
```

Abre `http://localhost:3000/orion-mx`.

## Producción

```bash
npm run build
npm start
```

## Archivos principales del rediseño

- `app/orion-mx/page.tsx`
- `components/orion-mx/OrionPage.tsx`
- `components/orion-mx/OrionMotion.tsx`
- `styles/orion.css`

Las imágenes y el modelo 3D de ORION permanecen dentro de `public/orion-mx`.
