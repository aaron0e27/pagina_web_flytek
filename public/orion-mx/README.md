# Recursos de ORION MX

- `orion-view-a.jpg` y `orion-view-b.jpg`: fotografías proporcionadas por el usuario el 4 de septiembre de 2026.
- `orion-hero.png`: tratamiento visual generado con la herramienta integrada de edición de imagen a partir de `orion-view-a.jpg`, para uso exclusivo en la portada y la tarjeta del producto.
- `orion-mx.glb`: modelo `orion3.glb` proporcionado por el usuario el 9 de septiembre de 2026, renombrado para conservar la ruta estable del visor web.

El tratamiento de portada es ilustrativo. Las fotografías originales se conservan en la galería de perspectivas. Sustituir el recurso cuando exista fotografía oficial de alta resolución o modelo GLB optimizado.
