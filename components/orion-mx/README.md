# ORION MX — componentes

`OrionPage.tsx` contiene la página completa: portada animada, navegación interna, estadísticas, visor 3D, selector de fotografías, ingeniería, cargas útiles, especificaciones, soporte y contacto.

`Orion3DViewer.tsx` carga el GLB únicamente cuando el visor se aproxima a la pantalla y ofrece giro, zoom y vistas predefinidas.
